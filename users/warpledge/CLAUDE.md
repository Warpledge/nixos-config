# warpledge

Owns this repo (`Warpledge/nixos-config`) and logs in on `eclipse` and `legion`, as admin
on both.

- Upstream maintainer: reviews pull requests from other people's copies with the
  `pr-review` skill and decides what goes into `modules/`.
- `docs/personal/` holds their notes (audio gear, the Android tablet, local installs,
  single-game notes); `docs/CLAUDE.md` indexes it. The `android-debloat-redo` skill is
  for their tablet.
- Private notes (real names behind stand-ins, playthrough records) sit in Claude Code's
  local memory on their machines, never in the repo.
