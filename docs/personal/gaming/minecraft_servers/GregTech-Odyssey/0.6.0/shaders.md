# GTO 0.6.0 Shaders

Since 2026-11-15 GTO runs the same Eclipse edit as GTNH, built for 1.20.1, with a
generated LabPBR pack that makes GT casings reflect and GT lights glow. The GTNH notes'
[shaders.md](../../GTNH/2.9.0/shaders.md#eclipse-with-chromapatch) cover ChromaPatch,
the Kura setup it comes from and the Warpledge edits; this page covers what differs.

## Versions

| Part | Version | File |
| --- | --- | --- |
| ChromaPatch | 1.0.3, Forge 1.20.1 jar | `mods/chromapatch-1.0.3-forge1201-1.20.1.jar` |
| Eclipse source | `e89e6c6` (2026-10-16), the GTNH pin | `shaderpacks/Eclipse-Shader-e89e6c6.zip` |
| Patched pack | Eclipse patch 1.0.3 (1.20.1) | `shaderpacks/Eclipse-Shader KuraEdit [OBS07-Chroma Patch].zip` |
| Pack in use | Warpledge Edit, 4 edits | `shaderpacks/Eclipse-Shader Warpledge Edit.zip` and its `.zip.txt` |
| PBR pack | generated by `pbrpack.py` | `resourcepacks/Warpledge GT PBR.zip`, 5th from the top of the list, under the xali's packs (2026-11-20) |

Oculus 1.8.0 and Embeddium come with dev27. ChromaPatch is client only (`clientOnly` in
[overlay.json](../tools/overlay.json)), and it accepts any server version.

Before 2026-11-15 GTO used a copy of the GTNH pack, which ChromaPatch had built with its
1.7.10 patch: its block list names GTNH blocks, so GT lamps and coils got no coloured
light. That pack is in `~/Documents/Minecraft_Servers/GTO-backups/shaders-2026-11-15/`
with the `options.txt` from before the change.

## Building the pack

Close the game first. ChromaPatch's 1.20.1 patch already lists GTCEu and gtocore's
borderless lamps, coils and fusion blocks. It writes the patched pack on launch, or:

```bash
cd ~/.local/share/PrismLauncher/instances/GregTech.Odyssey-0.6.0-dev27/minecraft
java -cp mods/chromapatch-1.0.3-forge1201-1.20.1.jar obs07.chroma.Patcher
python3 -I /etc/nixos-config/docs/personal/gaming/minecraft_servers/GTNH/2.9.0/eclipse-warpledge-edit/build.py "shaderpacks/Eclipse-Shader KuraEdit [OBS07-Chroma Patch].zip"
```

On 2026-11-15 the patch matched 21 of 21 files with no fuzzy hunks, and `build.py`
applied all its edits. Its fourth edit, the bordered lamps, matters only here: it adds
each `gtceu:<colour>_lamp` beside the `gtceu:<colour>_borderless_lamp` ChromaPatch lists,
so both kinds of lamp light the area in their colour. `build.py` refuses to overwrite
the pack in use, so move it aside first. The `.zip.txt` settings carry over; every key in
it exists in the 1.20.1 pack. They keep Emission Mode at 2 (Hardcoded + Lab Emission),
which the PBR pack needs, and Eclipse's reflections on terrain are on by default.

## The PBR pack

No LabPBR pack existed for GTCEu Modern as of 2026-11-15 (the ones found are for 1.12
GTCE), so [tools/pbrpack.py](../tools/pbrpack.py) generates one from the gtceu and gtocore
jars. It holds only generated `_s.png` maps, nothing copied from the jars. Rerun it after
a GTO update, since a new or renamed texture has no map until then:

```bash
nix-shell -p 'python3.withPackages(p: [p.pillow])' --run "python3 -I /etc/nixos-config/docs/personal/gaming/minecraft_servers/GregTech-Odyssey/tools/pbrpack.py ~/.local/share/PrismLauncher/instances/GregTech.Odyssey-0.6.0-dev27/minecraft/mods --replace"
```

`-n` counts without writing. The 2026-11-15 run gave 576 emissive, 644 metal and 34
plastic maps, and skipped 140 blank emissive textures, in about 3 seconds.

What gets a map, by path under `textures/block/` (the tables at the top of the script):

- **Emissive:** every `*_emissive*` and `*_bloom*` texture, which are the machine,
  lamp and cover overlays GTCEu draws full bright, and the active coils. Emission
  follows pixel brightness from 100 to 254, times the pixel's alpha; unlit pixels get 0,
  as in KuramA's GTNH packs.
- **Metal:** `casings/` and gtocore's `coil/`, including the `_ctm` variants: hulls,
  solid, pipe, gearbox, firebox, fusion, HPCA and gtocore's own casings. Smoothness 200
  to 232 and F0 120 to 150, scaled by each pixel's brightness within its texture so
  grooves read rougher. The values are close to Neon Horizons' GT casings on GTNH.
- **Plastic:** ABS, PTFE and other plastic casings get a flat semi-gloss (smoothness
  150, F0 10).
- **Matte, no map:** casings named for glass, wood, brick, stone, concrete, tiles,
  leather, ice, bio, filters and cleanroom parts, magic and mana, signs and the
  crafting table.

Each map of an animated texture gets an `_s.png.mcmeta` with the base texture's
`animation` block. Oculus reads a PBR texture's own metadata and squashes an animated
strip into one frame without it (`AtlasPBRLoader.java`, Asek3/Oculus `1.20.1-new`).

## Checking it

After a rebuild, look at a running machine, a lamp, an active coil, and a casing wall
outside and indoors. A casing that turns dark indoors or a texture that glows where it
shouldn't goes in the script's tables. `gto check GregTech.Odyssey-0.6.0-dev27` shows
new log errors; Oculus logs `Unable to parse metadata` or `not multiple of frame size`
for a bad map.
