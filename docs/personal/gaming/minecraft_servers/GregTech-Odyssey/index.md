# GregTech Odyssey Notes

Notes for GregTech Odyssey (GTO), a Forge 1.20.1 GregTech pack, kept per pack version.

| Version | Status | Instance |
| --- | --- | --- |
| [0.6.0](./0.6.0/index.md) | Current, dev builds, new world | `GregTech.Odyssey-0.6.0-dev27` |

The 0.5.6 instance (`GregTech.Odyssey-0.5.6-beta`) is retired and has no notes here; its
world was never carried over.

GTO grew out of GregTech Leisure (GTL). The pack is All Rights Reserved, GTOCore is
PolyForm Noncommercial, gtolib is closed source, and most of the community is Chinese,
so release notes and some in-game text are machine-translated.

The guides on [gtodyssey.com](https://gtodyssey.com) recommend not adding an I18N mod
or extra AE2 add-ons.
